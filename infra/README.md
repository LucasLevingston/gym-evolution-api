# Gym Evolution — Infrastructure

Terraform + AWS. Region: `us-east-1`. Inside the `gym-evolution-api` repo.

## Architecture

```
Internet → ALB (HTTP :80) → ECS Fargate (tsx src/app.ts)
                                ├── RDS PostgreSQL 16
                                └── ElastiCache Redis 7

ECR ──────────────────────────── shared between dev + prod
GitHub OIDC Provider ─────────── shared, account-level
SSM Parameter Store ──────────── secrets injected into ECS
CloudWatch ───────────────────── logs + alarms → SNS → email
```

API URL: ALB DNS name shown in `terraform output api_url` after apply.
Add Route53 + ACM later if a domain is acquired.

## Workspace structure

```
infra/
├── backend/        ← run once: creates S3 state bucket + DynamoDB lock
├── shared/         ← run once: creates ECR repo + GitHub OIDC provider
├── modules/        ← reusable modules (networking, ecs, rds, redis, alb, iam, cloudwatch)
└── environments/
    ├── dev/        ← VPC, ECS, RDS, Redis, ALB (small instances, FARGATE_SPOT)
    └── prod/       ← VPC, ECS, RDS Multi-AZ, Redis, ALB (larger instances, FARGATE)
```

## Environments

| Config | dev | prod |
|--------|-----|------|
| ECS CPU/RAM | 256/512 | 512/1024 |
| ECS desired count | 1 | 2 |
| ECS capacity | FARGATE_SPOT | FARGATE |
| RDS | db.t3.micro, single-AZ | db.t3.small, Multi-AZ |
| Redis | cache.t3.micro | cache.t3.small |
| RDS deletion protection | false | true |
| Log retention | 7 days | 30 days |

## First-time setup

**Run in this order. Each step is a prerequisite for the next.**

### Step 1 — Bootstrap remote state (run once, ever)

```bash
cd infra/backend
terraform init
terraform apply
```

### Step 2 — Shared resources (run once, ever)

```bash
cd infra/shared
terraform init
terraform apply
```

Creates: ECR repository `gym-evolution-api` and GitHub Actions OIDC provider.

### Step 3 — Deploy dev environment

```bash
cd infra/environments/dev
terraform init
terraform plan
terraform apply
```

### Step 4 — Set secrets in SSM (after dev apply)

```bash
aws ssm put-parameter \
  --name /gym-evolution/dev/jwt-secret \
  --value "your-strong-jwt-secret" \
  --type SecureString --overwrite

aws ssm put-parameter \
  --name /gym-evolution/dev/rapidapi-key \
  --value "your-rapidapi-key" \
  --type SecureString --overwrite
```

### Step 5 — Push first Docker image

```bash
# From repo root
ECR_URL=$(cd infra/environments/dev && terraform output -raw ecr_repository_url)

aws ecr get-login-password --region us-east-1 \
  | docker login --username AWS --password-stdin $ECR_URL

docker build -t gym-evolution-api .
docker tag gym-evolution-api:latest $ECR_URL:latest
docker push $ECR_URL:latest

# Trigger deployment
aws ecs update-service \
  --cluster gym-evolution-dev \
  --service gym-evolution-dev-api \
  --force-new-deployment
```

### Step 6 — Deploy prod (same as dev, different folder)

```bash
cd infra/environments/prod
terraform init
terraform plan
terraform apply -var="image_tag=v1.0.0"
```

## Daily usage

```bash
cd infra/environments/dev   # or prod

terraform plan              # preview changes
terraform apply             # apply changes
terraform output            # show API URL, ECR URL, cluster name, etc.
```

## Secrets managed in SSM

| Path | How set |
|------|---------|
| `/gym-evolution/{env}/database-url` | Auto-generated by terraform (RDS password) |
| `/gym-evolution/{env}/redis-url` | Auto-generated by terraform |
| `/gym-evolution/{env}/jwt-secret` | **Set manually** (step 4) |
| `/gym-evolution/{env}/rapidapi-key` | **Set manually** (step 4) |

## GitHub Actions OIDC

After `shared` apply, get the role ARN for each env:

```bash
cd infra/environments/dev && terraform output github_actions_role_arn
cd infra/environments/prod && terraform output github_actions_role_arn
```

Add to GitHub repo secrets as `AWS_ROLE_ARN_DEV` and `AWS_ROLE_ARN_PROD`.
